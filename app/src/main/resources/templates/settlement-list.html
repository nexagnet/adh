Nhập file đối soát J&T

File "Lịch sử đối soát" tải từ trang J&T: Dòng tiền, Lịch sử đối soát, cột "Tải về". Mỗi file là một kỳ (J&T đối soát thứ 2, 4, 6).

Về Nhập đơn
Đã nhập xong 1 kỳ đối soát (0 dòng) 0 đơn khớp với đơn đã có trong Adh, 0 đơn chưa có trong Adh. Bổ sung mã đơn cho 0 đơn, ngày ký nhận cho 0 đơn; tính lại 0 khách.
Những gì hệ thống làm và không làm với file này File có tên, SĐT và địa chỉ khách, nhưng Adh chỉ lưu mã vận đơn, mã đơn khách hàng, thời gian ký nhận và các khoản tiền; file gốc bị xóa ngay sau khi xác nhận. File này không tạo đơn hay khách mới và không đổi trạng thái đơn. Nhập lại một kỳ đã nhập thì kỳ cũ được thay bằng bản mới.

Tải file lên

Kỳ mới nhất đã nhập kết thúc ngày 01/01/2026; hãy tải các kỳ sau ngày đó.

Chưa nhập kỳ đối soát nào. Có thể chọn nhiều file cùng lúc (giữ phím Ctrl khi bấm chọn).
